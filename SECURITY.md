# Security Policy

## Supported versions

Security fixes target the latest `main` revision and the latest published
release. Older revisions may not receive backports.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Report it privately
through the repository's GitHub Security Advisories page or contact the
maintainer through the GitHub profile associated with `ahmadZMVD/pdf2md`.

Include:

- affected commit, release, or component;
- reproducible steps or a minimal proof of concept;
- impact and prerequisites;
- any proposed mitigation.

Please redact personal documents, credentials, access tokens, and system paths
that are not necessary to reproduce the issue. We will acknowledge receipt when
the report is actionable and coordinate disclosure after a fix is available.

## Scope notes

The application is designed for local processing. A local document should not
be uploaded by the application as part of normal conversion. Report any
unexpected network transmission as a security issue.
