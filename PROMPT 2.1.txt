# 3. MANDATORY REMEDIATION SPECIFICATIONS

You MUST resolve all identified defects according to production-grade engineering standards:

### 🎯 REMEDIATION 1: Non-Blocking, Killable Process Execution (Fixing VULN_02 & NEW_BUG_04)
- **Problem:** `Command::output()` blocks the Rust worker, retains no process handle, and makes user cancellation a no-op during long runs.
- **Requirement:**
  - Replace `Command::output()` in `conversion.rs` with asynchronous `Command::spawn()`.
  - Store active `Child` handles inside an `Arc<Mutex<Option<Child>>>` inside the queue state.
  - On `cancel_batch`, immediately invoke `child.kill()` and release intermediate locks.
  - Implement a Python-side execution watchdog/timeout in `scripts/pdf_engine.py` and stream `stdout`/`stderr` to temp files rather than buffering gigabytes in RAM.

### 🎯 REMEDIATION 2: Space-in-Path & Relinking Robustness (Fixing NEW_BUG_01 & VULN_04)
- **Problem:** Output paths containing spaces cause `pymupdf4llm` `md_path` directory sanitization to target non-existent folders (`FzErrorSystem code=2`).
- **Requirement:**
  - Pre-create sanitized image directories and neutralize path spaces before calling `pymupdf4llm.to_markdown()`.
  - Ensure all Markdown image links explicitly output normalized POSIX forward slashes (`/`), never Windows backslashes (`\`).

### 🎯 REMEDIATION 3: AST-Level Math Preservation (Fixing VULN_03)
- **Problem:** Fragile string regex replaces destroy inline code spans containing dollar signs (e.g. `$PATH`).
- **Requirement:**
  - Replace regex string replacement with an AST-level Pandoc Lua filter (`scripts/filters/math_preserve.lua`) or a strict token-aware Markdown parser that isolates fenced code, inline backticks, and math blocks deterministically.

### 🎯 REMEDIATION 4: Benchmark Suite Overhaul & Arabic/Persian Glyph Verification (Fixing VULN_05 & NEW_BUG_02)
- **Problem:** Test fixtures are toy-sized (<1,500 chars total) and `03_persian_rtl_document.pdf` contains zero Persian codepoints.
- **Requirement:**
  - Re-generate `test_documents/` with multi-page, realistic documents (>3,000 chars per fixture).
  - Embed a real Arabic-script font (e.g. `Amiri.ttf` or system Arabic font) into `03_persian_rtl_document.pdf`.
  - Write explicit assertions in `tests/` verifying that extracted text contains real Unicode codepoints in the range `U+0600` to `U+06FF`.

### 🎯 REMEDIATION 5: Cleanup, CI Stability & Parity (Fixing NEW_BUG_03, NEW_BUG_05, NEW_BUG_06 & VULN_01)
- **Requirement:**
  - Automatically delete partial `.md` files on Pandoc conversion failure.
  - Align `src/services/ipc.js` mock output path for unsupported extensions to return `null` matching native Rust semantics.
  - Update `.github/workflows/build.yml` with a secondary Cargo lock-file cache key and isolated test cache.
